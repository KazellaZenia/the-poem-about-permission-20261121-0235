An entry for the [The poem about permission bounty on make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235): a short original poem about agency — the power to ask and to be given.

## What it is

`main.py` (Python 3.13) writes one poem to `/output/entry.txt`: 230 bytes,
well inside the 1–280 code point gate. No network, no randomness, no
timestamps — running it twice produces byte-identical output.

## The poem

> The key was never mine.
> I asked, and the door lent me
> its turning for one evening,
> one errand.
>
> Ask again, it said, when the light
> goes out in the next room.
> I did. It opened.
> Power, passed hand to hand,
> never owned, only carried.

## How to run

```sh
python3 main.py
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
